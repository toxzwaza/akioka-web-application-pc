# 稟議書の表示デザイン変更（物品システムの承認画面に合わせる）証跡 2026-10-29

## 対象
- 共通部品 `resources/js/Components/Accept/ApprovalDocument.vue`
- 使っている画面：発注依頼一覧（稟議書・見積書モーダル／詳細の稟議書確認）、発注一覧（稟議書モーダル／詳細確認）

## 修正前の問題
- 灰色の入力欄風の箱に件名・発注内容・理由が並ぶだけで、起案者・品名・金額などの基本情報が出ていない
- 印刷ボタンを押しても動かない（`printApproval` が定義されていない）
- 承認印が出ない（承認データの項目名 `name`／`updated_at` と表示側の `user_name`／`created_at` が食い違い、却下・未承認も区別していない）

## 変更内容
| ファイル | 内容 |
|---|---|
| ApprovalDocument.vue | 物品システム（akioka-cloud-iot-legacy）承認画面の稟議書と同じ書式に変更（二重下線の表題・罫線表・見出し付き長文欄・スマホは一覧形式）。印刷ボタンを修正（稟議書部分だけ別ウィンドウで印刷）。添付画像と承認印（承認済みのみ）は残して書式に合わせた |
| OrderRequests.vue | 稟議書本体に発注依頼の項目（起案部門・起案者・希望納入日・発注先・品名・品番・単価・数量・合計）を合わせて渡す `approvalDocumentOf` を追加 |
| OrderRequestController.php | 一覧取得に依頼者の部門名 `request_user_process_name` を追加（processes を結合） |
| InitialOrderController.php／InitialOrders.vue | 依頼者の部門名 `order_user_process_name` を追加し起案部門に表示 |
