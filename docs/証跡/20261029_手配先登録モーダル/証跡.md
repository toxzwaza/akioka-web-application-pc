# 発注依頼一覧から手配先・リードタイム登録（マスタ反映）証跡 2026-10-29

## 対象
- PC版（akioka-web-application-pc）`Stock/OrderRequests` の発注先欄「取引先を設定してください。」

## 変更内容
- 修正前：リンクをクリックすると在庫詳細画面へ遷移し、そこで手配先を登録してから一覧に戻る必要があった
- 修正後：同じ画面でモーダルを開き、手配先（手配先マスタ全件から名前で検索）とリードタイム（日）を登録できる
  - 新API `POST /stock/order-requests/register/supplier`（`stock.registerSupplier`）
    - 在庫の手配先マスタ `stock_suppliers` に追加（同じ手配先が登録済みならリードタイムを更新）。メインの手配先が無い在庫ならメイン（適用中）にする
    - 発注依頼 `order_requests` の supplier_id・supplier_name・stock_supplier_lead_time・lead_time を更新
    - 1トランザクションで実行。手配先の存在・リードタイム（0以上の整数）をサーバー側でも検証。在庫未登録の発注依頼は登録不可
  - 登録後は一覧だけ取り直す（ページ再読み込みなし）。同じ物品の他の発注先未設定の依頼にも、一覧APIの既存の自動補完で反映される
  - 一覧APIの自動補完で発注先が入った行のリードタイムが「(未)」と表示されていたのを、マスタのリードタイムを表示するよう修正

## 検証環境（ローカルのみ。本番には接続していない）
- 127.0.0.1:8000（ローカルDB akioka_db）
- 発注依頼 6887 を一時的に在庫 12591（手配先未登録のインパクトドライバー）・発注先なしに変更して検証
